Flow A — BLS Market Data Pipeline

External market data ingestion (quarterly). BLS Pipeline reads SOC and MSA codes, batches API calls in groups of 50, transforms and upserts wage data.

Batches into groups of 50 (registered key limit) loop For each batch of ≤50 series IDs PL->>BLS: POST /timeseries/data/ — seriesid[], startyear, endyear BLS-->>PL: HTTP 200 — status, Results: series[] alt status = REQUEST_SUCCEEDED Note over PL: Parses wage values, maps data_type codes
Converts strings to numeric, handles suppressed as NULL else status = REQUEST_FAILED or empty Note over PL: Logs warning (FR-04)
Skips batch — no partial write (NFR-01a) else HTTP 429 — Rate limit PL->>DB: Writes FAILED to pipeline_run_log Note over PL: Preserves last-known-good dataset (NFR-03c) end end PL->>DB: Upserts rows INTO bls_wage_data ON CONFLICT DO UPDATE PL->>DB: Reconciles records_received vs records_written PL->>DB: Writes run summary to pipeline_run_log DB-->>UI: pipeline_run_log updated UI-->>Admin: Displays SUCCESS/FAILED status with record count

Flow B — CSV Internal Data Ingestion

Internal employee and job grade data upload path. On validation failure, no records are written (fail loudly — NFR-01a).

sequenceDiagram autonumber actor Admin as Total Rewards Admin participant UI as Streamlit Dashboard participant CSV as CSV Ingestion Module participant DB as PostgreSQL (Supabase) Admin->>UI: Uploads CSV file (Employee data or Job Grades) UI->>CSV: Passes DataFrame to validate_employees() or validate_job_grades() Note over CSV: Schema validation (FR-06)
Checks required columns, data types, non-null constraints alt Validation FAILS CSV-->>UI: Returns list of validation errors UI-->>Admin: Displays errors — no records written (NFR-01a) else Validation PASSES UI-->>Admin: "Validation passed — confirm load?" Admin->>UI: Clicks "Confirm and Load" UI->>CSV: Calls upsert_df(conn, df, UPSERT_SQL) loop For each row in validated DataFrame CSV->>DB: UPSERT ON CONFLICT DO UPDATE SET all fields end CSV->>DB: Writes run summary to pipeline_run_log DB-->>UI: Commit confirmed UI-->>Admin: Displays records written and duration end
