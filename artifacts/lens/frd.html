Document Contents

Lens_FRD_001 documents the full requirements for the Lens Sentiment & Text Analytics Engine, a tool that ingests open-ended survey and feedback text, runs it through an NLP pipeline (OpenAI API), and surfaces sentiment trends, theme clusters, and anomaly alerts on a Streamlit dashboard.

The document traces the requirements chain from business objectives (reduce time-to-insight from unstructured feedback) through to functional requirements for batch ingestion, API call orchestration, result persistence, and dashboard query read paths. Non-functional requirements cover API cost controls, latency SLAs, and auditability of model outputs.

  • Section 1 Business Problem & Current State: Manual survey analysis, inconsistent theme extraction, no trend view
  • Section 2 Stakeholder Map: CX Analysts, HR Business Partners, Operations Leads, Data Engineers
  • Section 3 Product Objectives (OBJ-01 to OBJ-05) with Success Indicators
  • Section 4 Batch Ingestion Requirements (FR-01 to FR-07): CSV upload, series context, validation rules
  • Section 5 NLP Pipeline Requirements (FR-08 to FR-14): OpenAI API orchestration, prompt design, retry logic
  • Section 6 Theme Extraction & Anomaly Detection (FR-15 to FR-20): clustering, RAG scoring, alert thresholds
  • Section 7 Dashboard & Visualization Requirements (FR-21 to FR-26): series comparison, drill-down, export
  • Section 8 Non-Functional Requirements: API cost controls, latency SLAs, model output auditability
  • Section 9 Data Model & Data Dictionary: 5-table PostgreSQL schema
  • Section 10 Out-of-Scope Items & Future Phases

The full FRD is available as a Word document on GitHub. It includes all functional requirements tables, MoSCoW prioritization, NFR rationale paragraphs, the data dictionary covering all five database tables, and API cost control specifications.
