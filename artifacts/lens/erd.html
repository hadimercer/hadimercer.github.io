Entity Relationship Diagram

analysis_results is the central hub table. series_index groups runs into longitudinal series. batch_records stores per-record NLP results. context_profiles holds optional org context. pipeline_run_log captures execution metadata.

Core

analysis_results: Central hub. All relationships converge here. Stores aggregated NLP output: sentiment split, themes, summary, anomaly count, and full per-record results as JSONB.

Series

series_index: Groups analysis runs into named longitudinal series. Enables trend comparison across time periods (e.g., "Q4 2025 CX Survey" series with 3 monthly runs).

Records

batch_records: Per-record scored results. One row per text input. Stores label, confidence score, deviation from batch mean, anomaly flag, and theme assignments.

Context

context_profiles: Optional org context injected into NLP prompts. Org name, industry, department, reporting period, and situational notes. Stored alongside result for audit.

Audit

pipeline_run_log: Execution metadata. API call counts, records submitted vs scored vs failed, duration, error detail. Supports pipeline monitoring and debugging.
