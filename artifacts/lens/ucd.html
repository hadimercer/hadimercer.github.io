Use Case Diagram

14 use cases grouped into 4 subsystems within the Lens System Boundary. Analyst drives all input and visualization use cases. Admin has read-only access to anomaly flags and history. OpenAI API is invoked for all NLP processing use cases.

Use Case Reference

UC IDNameGroupDescription
UC-01Upload Batch Text FileInputCSV or pasted text. Validates format, row count, encoding before accepting.
UC-02Label Batch & Domain TagInputHuman-readable source label and domain tag (CX/HR/OPS). Stored with analysis.
UC-02bEnter Context ProfileInputOptional org context: name, industry, department, period, notes. Injected into NLP prompt.
UC-02cLink to Analysis SeriesInputAssigns run to a named longitudinal series for trend comparison.
UC-03Validate & Preview RecordsInputParses file, shows record count and 5-row sample. Analyst confirms before pipeline runs.
UC-04Run Sentiment AnalysisNLP PipelineCore step: each record sent to OpenAI for label (pos/neu/neg) and confidence score.
UC-05Extract Recurring ThemesNLP PipelineBatch-level prompt: top 5-8 themes with frequency and dominant sentiment.
UC-06Generate Executive SummaryNLP Pipeline2-3 sentence narrative: sentiment distribution, dominant themes, notable patterns.
UC-07Flag Sentiment AnomaliesNLP PipelineRecords deviating ±2σ from batch mean tagged as anomalies.
UC-08View Sentiment BreakdownVisualizationDonut chart + histogram: positive/neutral/negative %.
UC-09View Theme HeatmapVisualizationGrid: themes vs sentiment polarity, with representative quotes on hover.
UC-10View Sentiment Over TimeVisualizationLine chart by day/week when timestamp column present.
UC-11View Anomaly FlagsVisualizationFiltered list of outlier records with deviation value and type.
UC-12Save Analysis to HistoryPersistenceFull result written to PostgreSQL with unique analysis_id.
UC-13Browse Past AnalysesPersistencePaginated list of stored analyses grouped by series.
UC-14Export Results CSVExportPer-record scores and theme assignments as downloadable CSV.
