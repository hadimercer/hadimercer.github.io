Process Diagrams: 4 Workflows × AS-IS / TO-BE

8 diagrams total. AS-IS shows the current manual or undocumented state. TO-BE shows the Cadence system target state. Select a workflow and view below.

AS-IS

WF1 · Headcount Reporting: Manual CSV Reporting

HRBP exports CSV from HRIS, manually cleans and formats in Excel, builds pivot tables and charts, emails stakeholders. Follow-up questions restart the entire cycle.

flowchart LR HRBP(["HRBP / HR Admin"]) -->|"Export headcount data"| Export["Export CSV\nfrom HRIS"] Export -->|"Manually clean data"| Clean["Clean &\nFormat in Excel"] Clean -->|"Build charts manually"| Charts["Build Pivot\nTables & Charts"] Charts -->|"Email report"| Email["Email to\nStakeholders"] Email -->|"Follow-up questions"| QA{Questions\nReceived?} QA -->|"Yes, re-run"| Export QA -->|"No"| Done([End])
TO-BE

WF1 · Headcount Reporting: Automated Pipeline

HR Admin uploads CSV via dashboard. System validates schema, confirms load, triggers pipeline, auto-computes metrics (delta, tenure, attrition rate), and updates the live dashboard instantly.

flowchart LR HRBP(["HR Admin"]) -->|"Upload CSV"| Upload["Upload CSV\nvia Dashboard"] Upload -->|"Validate schema"| Validate{Validation\nPassed?} Validate -->|"No, show errors"| Errors["Display\nValidation Errors"] Errors --> Upload Validate -->|"Yes"| Confirm["Confirm\n& Load"] Confirm -->|"Trigger pipeline"| Pipeline["Pipeline\nRun: headcount_snapshots"] Pipeline -->|"Compute metrics"| Metrics["Auto-compute:\nDelta, Tenure, Attrition Rate"] Metrics -->|"Update dashboard"| DB[("PostgreSQL\nheadcount_snapshots")] DB --> Dashboard["Live Dashboard\nInstant Access"] Dashboard --> Done2([End])
AS-IS

WF2 · Compensation Review: Spreadsheet Merit Cycle

CHRO distributes Excel spreadsheets. Managers fill in recommendations. HRBP manually consolidates multiple sheets, performs manual band compliance check, then CHRO approves via email chain.

flowchart LR CHRO(["CHRO"]) -->|"Open cycle"| Spreadsheet["Distribute\nExcel Spreadsheets"] Spreadsheet -->|"Managers fill in"| MgrInput["Manager Merit\nRecommendations"] MgrInput -->|"Consolidate manually"| Consolidate["HRBP Consolidates\nMultiple Sheets"] Consolidate -->|"Check band compliance"| ManualCheck["Manual Band\nCompliance Check"] ManualCheck -->|"Approve"| Approve["CHRO Approval\n(email chain)"] Approve --> End2([End])
TO-BE

WF2 · Compensation Review: Eligibility Engine

CHRO opens cycle in system. Eligibility engine auto-determines eligible employees from WF1 data. Managers submit recommendations via dashboard. Band max flag triggers CHRO review path. HR approval workflow closes cycle.

flowchart LR CHRO(["CHRO"]) -->|"Open cycle"| OpenCycle["Open Merit\nCycle in System"] OpenCycle -->|"Auto-determine"| EligEngine["Eligibility Engine\nRuns Against WF1 Data"] EligEngine -->|"Flag eligible employees"| MgrDash["Manager Dashboard:\nView Eligible Reports"] MgrDash -->|"Submit recommendations"| Rec["Submit Merit\nRecommendations"] Rec -->|"Check band max flag"| BandCheck{Exceeds\nBand Max?} BandCheck -->|"Yes, flag"| Flag["Flag for\nCHRO Review"] BandCheck -->|"No"| HRApprove["HR Approval\nWorkflow"] Flag --> HRApprove HRApprove --> CloseCycle["Close Cycle\n& Archive"] CloseCycle --> End3([End])
AS-IS

WF4 · Performance Management: Undocumented Reviews

Manager conducts informal verbal check-ins with no structured record. Annual review is retrospective with no documentation trail: high bias risk and no data to inform merit decisions.

flowchart LR Manager(["Manager"]) -->|"Informal feedback"| Verbal["Verbal / Ad-hoc\nCheck-ins"] Verbal -->|"No documentation"| NoRecord["No Structured\nRecord Kept"] NoRecord -->|"Annual review"| AnnualReview["Annual Performance\nReview (Retrospective)"] AnnualReview -->|"Bias risk"| Decision["Rating Decision\nWith No Trail"] Decision --> End4([End])
TO-BE

WF4 · Performance Management: Weekly 1:1 + Monthly + Quarterly

Structured cadence: weekly 1:1 capture, monthly check-ins with employee acknowledgement, quarterly formal review with HR approval. Output feeds WF2 (merit eligibility) and WF3 (attrition risk).

flowchart LR Manager(["Manager"]) -->|"Each week"| WeeklyCapture["Capture Weekly 1:1:\nTopics · Actions · Sentiment"] WeeklyCapture --> MonthlyCapture["Monthly Check-in:\nGoals · Achievements · Development"] MonthlyCapture --> EmpAck["Employee\nAcknowledges Check-in"] EmpAck --> QuarterlyReview["Quarterly Review:\nSelf-assess → Manager → HR Approval"] QuarterlyReview -->|"Feeds merit eligibility"| WF2["Trigger\nWF2 Merit Cycle"] QuarterlyReview -->|"Feeds risk scoring"| WF3["Update\nWF3 Attrition Score"] WF2 --> End5([End])
AS-IS

WF3 · Attrition Risk Scoring: Reactive Resignation Response

No proactive signal. Organization only becomes aware of flight risk when resignation is submitted. Exit interview conducted if time permits. Post-hoc analysis provides no preventive value.

flowchart LR Employee(["Employee"]) -->|"Submits resignation"| Resignation["Resignation\nReceived"] Resignation -->|"Exit interview"| ExitInt["Exit Interview\n(if conducted)"] ExitInt -->|"Post-hoc analysis"| PostHoc["Retrospective\nAnalysis Only"] PostHoc -->|"No proactive signal"| Missed["Risk Was Not\nIdentified in Advance"] Missed --> End6([End])
TO-BE

WF3 · Attrition Risk Scoring: Proactive Scoring Engine

Composite 0-100 risk score aggregates signals from WF1 (tenure/salary), WF2 (merit history), and WF4 (ratings/sentiment). RED flags trigger retention action logging. AMBER raises dashboard alert for monitoring.

flowchart LR WF1Score["WF1 Data:\nTenure, Salary"] -->|"compa-ratio, time-in-role"| ScoreEngine(("Risk Scoring\nEngine")) WF4Score["WF4 Data:\n1:1 Freq, Ratings"] -->|"sentiment, check-in freq"| ScoreEngine WF2Score["WF2 Data:\nMerit History"] -->|"time since merit"| ScoreEngine ScoreEngine -->|"Composite 0-100"| RAG{RAG\nStatus} RAG -->|"RED < 40"| Alert["Alert:\nHR + Manager Dashboard"] RAG -->|"AMBER 40-69"| Monitor["Monitor:\nFlagged on Dashboard"] RAG -->|"GREEN >= 70"| Clear["No Action\nRequired"] Alert -->|"Create retention action"| RetentionAction["Log Retention\nAction in System"] RetentionAction --> End7([End])
